# V8.2 实验补充报告

## 1. 实验目的

本轮针对 v8.1 台账中仍缺少的三类证据进行补充：

1. 用与 targeted ADT mask 完全相同的特征数构造 random null，判断 targeted mask 的退化是否只是“删掉特征数量多”的结果。
2. 在 PDC101 相同 external holdout cell 上，对 MOSAIC-HPM-lite 与 MMoCHi 做逐 cell 配对错误审计，而不是只比较独立汇总指标。
3. 将已有的审计决策迁移到 GSE164378 5P assay cohort，并检查 donor/study provenance，避免把同研究数据误写成独立外部验证。

本轮没有改写正文性能结论，也没有把任何结果升级为 universal SOTA、arbitrary missing-modality robustness 或 independent external generalization。证据先写入实验目录，再同步 claim registry 和 v8.1 repair ledger。

## 2. PBMC 尺寸匹配随机 ADT null

实验脚本：`experiments/exp_missing_modality/mosaic_n_v82/run_size_matched_random_adt_null.py`。

协议沿用 v33 PBMC donor-disjoint frozen-checkpoint evaluation：8 个 test donor、3 个 model seed，共 24 个 donor×seed 单位；每个单位使用同一个冻结 checkpoint 和同一批 known-label test cells。新增 `random_size_matched_6` 与 `random_size_matched_15`，分别随机屏蔽 6 个和 15 个可用 ADT 特征，mask 由 feature name、donor 和 seed 预先生成，在该单位内对所有 cell 固定。mask 不读取 test label、prediction、threshold 或 test error。

产物：

- `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/results_summary.csv`
- `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/per_class_metrics.csv`
- `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/mask_manifest.csv`
- `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/mask_summary.csv`
- `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/config.yaml`
- `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/split_seed_metadata.json`
- `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/preflight.json`

关键汇总如下，数值是 24 个单位相对 full condition 的平均 delta：

| 条件 | 屏蔽数 | W-F1 delta | M-F1 delta | B-ACC delta | 负向 W-F1 单位 |
|---|---:|---:|---:|---:|---:|
| random size-matched 6 | 6 | -0.000490 | -0.000158 | -0.000108 | 17/24 |
| targeted memory | 6 | -0.002555 | -0.006572 | -0.003865 | 23/24 |
| random size-matched 15 | 15 | -0.001831 | -0.004406 | -0.004216 | 22/24 |
| targeted T-cell | 15 | -0.008693 | -0.021330 | -0.014660 | 24/24 |

解释：在当前 PBMC 协议中，targeted mask 的平均退化明显大于相同特征数的 random null，尤其是 15-feature 条件。这使 targeted-panel sensitivity 的解释更有针对性，不再只是 feature-count confounding。但该实验仍是固定 ADT panel、固定 checkpoint 和 donor protocol 下的诊断，不能推出任意 panel、任意蛋白缺失或真实临床缺失模态下的 robustness。

## 3. PDC101 配对错误审计

脚本：`experiments/exp_generalization/mosaic2_pdc101/run_pdc101_paired_audit.py`。

MOSAIC 与 MMoCHi 的预测文件通过 exact cell ID 一对一连接，最终 2,098/2,098 个 external holdout cell 对齐，truth label 完全一致。两套元数据都确认 HTO 未作为模型输入。MOSAIC-HPM-lite 的 ACC 为 0.93756，MMoCHi 为 0.93470；MOSAIC-only correct 为 80，MMoCHi-only correct 为 74，paired accuracy delta 为 +0.002860，但 exact two-sided McNemar `p=0.687149`，因此不能写成显著或稳定 superiority。

产物：

- `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/results_summary.csv`
- `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/per_cell_paired_outcomes.csv`
- `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/statistical_tests.json`
- `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/gate_distribution.csv`
- `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/confidence_distribution.csv`

MOSAIC `adt_gate` 仅作为 MOSAIC 内部的 boundary-audit field 汇总：central-memory rows 的均值为 0.7051，其他 rows 为 0.6078。MMoCHi 保存的是 certainty，而不是同定义的 modality weight，因此跨方法 weight-distribution test 标记为 `not_estimable`，没有从最终标签反推任何权重。

## 4. GSE164378 5P audit transfer

脚本：`experiments/exp_generalization/mosaic2_pdc101/run_secondary_cohort_audit_transfer.py`。

现有 full-panel prediction artifact 与 `data/GSE164378/gse164378_5p_protein.h5ad` 逐 cell 对齐，共 49,147 cells。h5ad 中 donor 为 P1--P8，与 PBMC 主协议 donor 集合相同；policy metadata 是 `validation_only`，external labels 没有参与 policy selection。因此这项实验可作为 same-study assay-cohort replication，但不能叫 independent external validation。

锁定的 full-accept decision 在该队列上的 retrospective audit 为：L3 accuracy 0.728915，parent-safe rate 0.897451，accept rate 1.0。由于没有 fallback cells，不能把这个结果叙述成 selective-risk transfer 的成功。完整产物位于：

`results/experiments/v8.2_missing_modality_pdc_audit/secondary_cohort/`

其中 `preflight.json` 和 `cohort_identity_audit.csv` 明确记录了 `independent_external_cohort=false`。

## 5. 结论与论文使用边界

- 可以更新 panel-masking evidence：targeted 6/15-feature mask 的退化超过同尺寸 random null，但仍只能说是 protocol-specific targeted-panel sensitivity。
- 可以把 PDC101 的点估计差异改成 paired audit result；不能声称 MOSAIC 显著超过 MMoCHi。
- 可以增加同研究 assay-cohort replication 作为审计迁移证据；不能把它升级成独立 donor 或 cross-study generalization。
- 本轮不修改主文表格、Fig1 或投稿 PDF。若后续要把新结果放入论文，必须先从这些 CSV/JSON 产物生成 table fragment，再同步正文、caption、supplementary index 和编译审计。
