# V8.2 缺失模态与配对审计证据闭环实验计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不扩大当前论文 claim 边界的前提下，补齐尺寸匹配的随机 ADT 空值对照、PDC101 配对错误审计，并对第二队列审计迁移进行可行性判定，形成可复核的实验产物。

**Architecture:** 以现有 v33 PBMC strict nested donor-disjoint 冻结 checkpoint 为主线，只新增与 targeted ADT mask 具有相同特征数的随机 mask，不重新选择测试集策略或测试标签阈值。PDC101 只使用已经生成的无 HTO 外部测试预测做 paired analysis，不重新训练；第二队列先做数据、标签、预测和审计字段的 provenance preflight，只有协议可比且不引入泄漏时才执行，否则生成明确的 blocked/scope-pushback 产物。所有证据先写入 CSV/JSON/NPZ/README/config/log，再决定是否修改 registry 或论文。

**Tech Stack:** Python 3, PyTorch/CUDA, pandas, NumPy, SciPy, scikit-learn, existing `TOSICA` and `MMoCHi` conda environments, shell-based audit scripts.

---

## 研究边界与统一规则

- 主线 claim 仍是：MOSAIC 是在 donor shift 与不完整蛋白面板压力下可审计的分支监督 CITE-seq annotation framework；本轮不预设会提升 ACC/W-F1/M-F1，也不把任何新结果写成 universal SOTA、open-set solved 或 missing-modality solution。
- 任何 mask 都必须在 test prediction 生成前固定；mask 只依赖特征名、预先声明的 seed 和 fold/seed 元数据，不能使用测试标签、测试误差、阈值或逐类结果选择。
- 所有结果记录数据集、split unit、checkpoint/seed、输入模态、ADT feature count、mask seed、聚合模式、预测产物路径和 caveat。
- 新实验使用日期前缀输出目录，至少包含 `README.md`、`config.yaml`、`run.log`、`split_seed_metadata.json`、`results_summary.csv`；如果产生逐 cell 结果，另外保存 `predictions.csv` 或 `predictions.npz`。
- 在证据 artifact 完成前不编辑摘要、Results、Discussion、caption 或 claim registry。

## Task 2: PBMC 尺寸匹配随机 ADT null

**Files:**
- Create: `experiments/exp_missing_modality/mosaic_n_v82/run_size_matched_random_adt_null.py`
- Create: `experiments/exp_missing_modality/mosaic_n_v82/test_size_matched_random_adt_null.py`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/README.md`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/config.yaml`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/run.log`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/split_seed_metadata.json`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/results_summary.csv`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/per_donor_seed_metrics.csv`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pbmc_random_adt_null/mask_manifest.csv`

**Protocol:**

1. Reuse the existing strict nested donor-disjoint PBMC evaluation units and frozen checkpoints; do not retrain or change checkpoint selection.
2. Preserve the old deterministic random-mask rows for historical comparability. Add independent size-matched random masks with counts equal to each targeted mask (six-feature and fifteen-feature); use a declared seed per fold/checkpoint, generated only from the eligible ADT feature list after alias normalization.
3. Keep full input, existing random percentage conditions, targeted-six, targeted-fifteen, random-six and random-fifteen as separate conditions. Never merge a random size-matched row into a targeted row or a train-time dropout row.
4. For every donor/checkpoint/condition record ACC, weighted F1, macro F1, balanced accuracy, ECE and Brier score where the existing evaluator supports them, plus cell count, class count, modality and mask provenance. Aggregate only after per-unit rows exist; report donor means and paired deltas against full input.
5. Assert that every mask is fixed across cells within a unit, has the intended count, contains no unavailable feature, and was generated without labels or predictions.

**Success criteria:** all declared units run without leakage and produce a complete manifest and per-unit CSV; the direction of targeted versus size-matched random effects can be inspected. No minimum gain is assumed. A null or negative result is valid evidence and must be reported honestly.

**Stop criteria:** missing checkpoint/cache, inconsistent feature names, test-label-dependent mask construction, partial unit completion, OOM, or inability to establish split/seed provenance. In these cases write a blocked report and do not alter manuscript claims.

**Test:**

```bash
conda run -n TOSICA python experiments/exp_missing_modality/mosaic_n_v82/test_size_matched_random_adt_null.py
```

预期：mask count、feature eligibility、same-within-unit、label independence 和 output schema tests pass。

- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/README.md`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/config.yaml`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/run.log`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/split_seed_metadata.json`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/results_summary.csv`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/per_cell_paired_outcomes.csv`
- Create: `results/experiments/v8.2_missing_modality_pdc_audit/pdc101_paired_audit/statistical_tests.json`

**Protocol:**

1. Join MOSAIC/HPM-lite and official MMoCHi predictions only on an exact held-out cell identifier, then assert identical truth labels and no duplicate IDs.
2. Compute paired correctness counts and exact or asymptotic McNemar test with the discordant-cell table, effect direction, and confidence interval where supported. Do not use independent-sample tests for paired predictions.
3. If prediction files contain branch/boundary scores or modality weights with documented provenance, compare their distributions on the same held-out cells using paired tests and report the estimand. If those columns do not exist or were not saved under the valid no-HTO run, write `not_estimable` with the missing field and source path; never reconstruct a weight from final labels.
4. Preserve the no-HTO constraint and report HTO leakage exclusions. The analysis is an audit of existing predictions, not a new training claim.

**Success criteria:** exact cell alignment is established, paired statistics and provenance are saved, and any non-estimable analysis is explicitly documented.

**Stop criteria:** mismatched identifiers/labels, hidden train/test overlap, missing true-label provenance, or weights that cannot be tied to the evaluated run.
